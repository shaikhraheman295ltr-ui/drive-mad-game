# Drive Mad - Enhanced Driving Game

A WebAssembly driving game with 26+ visual overlay effects — rain, lightning, fireflies, drift smoke, Nyan Cat, photo mode, recording, and more.

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?logo=vercel)](https://drive-mad-game-neon.vercel.app)

**Live Demo:** [https://drive-mad-game-neon.vercel.app](https://drive-mad-game-neon.vercel.app)

## Controls

| Key | Action |
|-----|--------|
| Arrow Keys / WASD | Drive |
| **P** | Photo mode (freeze) |
| **F** | Cycle photo filter |
| **K** | Screenshot (PNG) |
| **N** | Nyan Cat overlay |
| **L** | Festive border lights |
| **Shift+A** | Autopilot |
| **R** | Record video (WebM) |
| **M** | Chiptune music |

## Features

- 26+ visual overlay effects (rain, lightning, starfield, headlights, drift smoke, confetti, sun glare, and more)
- All effects are CSS/JS overlays — original WASM engine untouched
- Speedometer HUD, RPM tachometer, FPS counter
- Rear-view mirror PiP display
- Random achievements and screen shake

## Built With

- Original game by [Martin Magni](https://openprocessing.org)
- Pure JavaScript overlays with Canvas2D + Web Audio API
